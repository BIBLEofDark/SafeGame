# 🚢 雨夜长江航道趸船 · 安全隐患排查小游戏

基于 **Three.js** 开发的 3D 微缩拟真长江航道趸船安全巡检排查互动游戏。

## 🌟 游戏亮点与特性
- **🌧️ 雨夜沉浸式微缩景观**：动态长江流水着色器、雨滴滑落雨痕、微风旗帜波动、避雷针、航标红绿灯与夜景氛围。
- **🔍 16 类航道典型安全隐患**：涵盖生活用电（电热水壶干烧冒烟无人看管）、电气安全（外墙电线破损裸露跳火、射灯短路频闪）、消防应急（太平斧缺失、灭火器过期、消防栓被遮挡）、高空防坠（二层护栏倚靠打手机分神、护栏豁口）、通航标识（顶楼“長江航道”发光字单字故障熄灭）等。
- **🌱 三档排查难度**：
  - **简单模式**：随机抽查 6 个隐患，限时 2.5 分钟，带有橙色脉冲球定位提示；
  - **普通模式**：随机抽查 8 个隐患，限时 1分45秒，带有橙色脉冲球提示；
  - **困难模式**：随机抽查 10 个隐患，限时 1分15秒，无脉冲球提示，纯考验专业巡检眼力！
- **📱 移动端与电脑端完美响应式**：轻量级紧凑 HUD，触屏双指缩放/单指旋转流畅自如。
- **🎮 纯享观赏模式**：可一键隐藏所有界面与标记，自由欣赏雨夜趸船生活微缩模型。

## 🚀 在线体验
直接打开 `safegame2.html` 或 `index.html` 即可在现代浏览器中直接运行！
