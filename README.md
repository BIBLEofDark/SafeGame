## 🌟 游戏亮点与专业拟真特性

- **🌧️ 雨夜沉浸式微缩趸船**：
  - 动态江水波流着色器、雨滴划落涟漪、五星红旗微风飘拂。
  - 严格遵循内河通航标示：**顶板红绿舷灯按规范修正**（红灯位于趸船背面左舷，绿灯位于正面右舷，配备遮光隔板与高亮警示泛光点光源）。
  - **船体背面全景巡视**：底部 HUD 专属配备 `[🔄 巡视船体背面]` 一键运镜视角，支持 360° 无死角巡查江面与背侧舱壁。
- **🏗️ 严密建筑结构与内河安全标识**：
  - 各层外侧楼梯结构规整贴合右侧舱壁，二层、三层甲板对应精准**镂空楼梯间梯口（带防踢踢脚板）**，消除模型穿模。
  - 甲板舱（H10）黄色安全逃生直梯**紧贴内侧舱壁**牢固布置。
  - 墙面“安全逃生梯”反光标识、右舷“太平斧专用位”固定背板与双挂钩**全程常驻船体**，高度契合内河趸船安全规范。
  - 趸船正立面“安全生产公示”宣传栏采用高精度矢量排版算法，三栏对称图文布局，彻底杜绝文字溢出。

## 🎮 游戏模式与规则

- **紧凑节奏（全面提速 1/2）**：
  - **简单模式**：随机抽取 6 处隐患，限时 2 分 30 秒（150s），带橙色呼吸脉冲球导航指引；
  - **普通模式**：随机抽取 8 处隐患，限时 1 分 45 秒（105s），带橙色呼吸脉冲球提示；
  - **困难模式**：随机抽取 10 处隐患，限时 1 分 15 秒（75s），**关闭脉冲球提示**，全凭巡检专业眼力！
- **响应式 UI 适配**：
  - 手机竖屏/横屏自适应紧凑顶部导航栏与状态卡，菜单紧凑合理不遮挡视野。
  - PC 端模式切换配有智能加载遮罩与快速响应机制。
- **纯享观赏模式**：
  - 一键隐藏所有巡检 UI 与隐患标记，畅享 3D 雨夜趸船生活场景微缩模型。
